아이패드 종류부터 확인

1분 · 6단계에서 갈립니다

아이패드에서 설정 앱을 열고 왼쪽 목록을 보세요.

  • 셀룰러 항목이 보이면 → 셀룰러 모델
  • 안 보이면 → Wi-Fi 전용 모델

기억해 두세요. 어느 쪽이든 다 됩니다. 연결 방법만 달라집니다.

1

Python 설치

5분 · 한 번만

이 프로그램을 돌리는 데 필요합니다.

  1. python.org/downloads 접속
  2. 노란색 Download Python 큰 버튼 클릭
  3. 받은 파일 실행
⚠ 여기가 제일 중요합니다

설치 창이 뜨면 Install Now를 바로 누르지 마세요.

창 맨 아래에 체크박스가 있습니다. Add python.exe to PATH 를 반드시 체크한 다음 Install Now를 누르세요.

이걸 빠뜨리면 나중에 “Python을 찾을 수 없다”는 메시지가 나옵니다. 그때는 Python을 지우고 이 단계부터 다시 하면 됩니다.

2

프로그램 내려받기

2분

  1. 이 링크를 엽니다
  2. 오른쪽 위 초록색 Code 버튼 클릭
  3. Download ZIP 선택
  4. 받은 ZIP 파일을 바탕화면에 놓고, 오른쪽 클릭 → 압축 풀기

긴 이름의 폴더가 생깁니다. 이름은 바꾸셔도 됩니다.

3

실행하기

2분 · 첫 실행만 오래 걸립니다

폴더를 열면 run.bat 파일이 있습니다. 더블클릭하세요.

검은 창이 뜨고 글자가 주르륵 올라갑니다. 필요한 것들을 인터넷에서 받는 중이니 1~2분 그냥 기다리세요.

파란 경고창이 뜨면

“Windows의 PC 보호” 창은 인터넷에서 받은 파일이라 뜨는 것입니다. 추가 정보 → 실행 을 누르세요.

4

방화벽 허용

10초 · 가장 흔한 실패 지점

“Windows Defender 방화벽에서 이 앱의 일부 기능을 차단했습니다” 창이 뜹니다.

⚠ 여기서 취소하면 아이패드가 접속 못 합니다

개인 네트워크에 체크가 되어 있는지 확인하고 액세스 허용을 누르세요.

실수로 취소했다면: Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽을 통해 앱 허용 → 설정 변경 에서 Python을 찾아 체크하세요.

5

QR 코드가 뜹니다

확인만 하세요

✓ 이게 보이면 잘 되고 있는 겁니다

“아이패드를 연결하세요” 라는 창이 뜨고 QR 코드가 보입니다.

이 창은 그대로 두세요. 7단계에서 씁니다.

6

아이패드 연결

3분 · 0단계에서 확인한 모델에 따라 갈립니다

셀룰러 모델

USB 케이블로 연결

  1. 아이패드를 노트북에 USB로 연결
  2. 아이패드에 뜨는 신뢰 누르기
  3. 아이패드 설정 → 개인용 핫스팟 → 다른 사람의 연결 허용 켜기
⚠ 데이터 요금 아끼기 — 꼭 하세요

USB로 연결하면 Windows가 노트북의 인터넷을 전부 아이패드 셀룰러로 내보냅니다. 강의 중에 Windows 업데이트가 돌면 데이터가 훅 나갑니다.

설정 → 네트워크 및 인터넷 → 이더넷 → 아이패드 연결 클릭 → 종량제 연결을 켬으로.

1분이면 되고, 한 번만 해두면 계속 유지됩니다.

개인용 핫스팟이 안 보이거나 회색이면

데이터 요금제가 비활성 상태입니다. 이 기능은 요금제가 살아 있어야 켜집니다. 요금제를 안 쓰신다면 아래 Wi-Fi 전용 방법을 그대로 쓰시면 됩니다. 셀룰러 모델에서도 잘 됩니다.

노트북이 아이패드를 못 알아보면 Apple Devices 앱을 설치하세요. 설치만 하면 되고 실행할 필요는 없습니다.

Wi-Fi 전용 모델

노트북이 Wi-Fi를 쏘게 하기

강의실에 인터넷이 없어도 되는 방법입니다.

  1. 노트북 설정 → 네트워크 및 인터넷 → 모바일 핫스팟 켜기
  2. 거기 표시된 네트워크 이름과 암호 확인
  3. 아이패드 설정 → Wi-Fi 에서 그 이름으로 접속
참고

아이패드에 “인터넷 연결 안 됨”이라고 떠도 정상입니다. 노트북과 아이패드가 서로 통하기만 하면 됩니다.

연결 방식을 바꿨다면

노트북의 검은 창에서 Ctrl + C 를 눌러 끄고 run.bat을 다시 실행하세요. 주소가 바뀌기 때문입니다.

7

QR 코드 비추기

10초

  1. 아이패드에서 카메라 앱을 엽니다
  2. 노트북 화면의 QR 코드를 비춥니다 (사진 찍지 말고 그냥 비추기만)
  3. 화면 위쪽에 뜨는 노란 알림을 누릅니다
✓ 성공

Safari가 열리면서 노트북 화면이 아이패드에 나타납니다.

QR이 안 읽히면, 노트북 창에 크게 적힌 주소(http://172.20...)를 아이패드 Safari 주소창에 직접 입력해도 됩니다.

8

전체화면으로 만들기

20초 · 권장

Safari의 공유 버튼(네모에 화살표) → 목록을 아래로 내려서 홈 화면에 추가 → 추가

아이패드 홈 화면에 아이콘이 생깁니다. 다음부터 이 아이콘으로 열면 Safari 주소창 없이 전체화면으로 뜹니다. 강의할 때 훨씬 낫습니다.

이제 쓰면 됩니다

애플펜슬로 아이패드에 그으면 노트북 화면에도 똑같이 그려집니다. 손을 화면에 짚어도 선이 안 그어지니 편하게 쓰세요.

다음 강의부터는

준비는 끝났습니다. 매번 할 일은 이것뿐입니다.

  1. run.bat 더블클릭
  2. 아이패드 연결 (USB 꽂기 또는 노트북 핫스팟 켜기)
  3. 아이패드 홈 화면 아이콘 누르기

온라인 강의를 하신다면

기본 상태로는 Zoom 화면 공유에 필기가 보이지 않습니다. 수강생에게 마킹을 보여주려면 실행 방법을 바꿔야 합니다.

폴더의 빈 곳에서 Shift + 오른쪽 클릭 → 여기에 PowerShell 창 열기 를 누른 뒤 아래를 붙여넣으세요.

.\run.bat --share-ink

대면 강의(프로젝터)라면 run.bat 그냥 더블클릭으로 충분합니다.

잘 안 될 때

“Python을 찾을 수 없습니다”

1단계의 Add python.exe to PATH 체크를 빠뜨린 것입니다. Python을 지우고 1단계부터 다시 하세요.

QR을 찍었는데 “서버에 연결할 수 없음”

거의 항상 방화벽입니다. 4단계를 다시 보세요.

학교나 회사 Wi-Fi를 쓰고 있다면, 그 Wi-Fi가 기기 간 통신을 막는 것일 수도 있습니다. 6단계의 노트북 모바일 핫스팟 방식으로 바꾸면 대부분 해결됩니다.

아이패드 설정에 “개인용 핫스팟”이 없습니다

Wi-Fi 전용 모델이거나 데이터 요금제가 비활성 상태입니다. 정상입니다. 6단계의 Wi-Fi 전용 모델 방법을 쓰시면 됩니다.

펜슬로 그은 위치와 노트북에 나오는 위치가 다릅니다

화면 배율 문제일 수 있습니다. 어느 정도 어긋나는지 알려주세요.

노트북 화면이 클릭이 안 됩니다

원래는 필기 위로 클릭이 통과해야 정상입니다. 이 증상이 나오면 알려주세요.

그림이 뚝뚝 끊깁니다

PowerShell에서 .\run.bat --width 960 으로 실행해 보세요. 화질을 조금 낮추고 속도를 올립니다.

막히면 몇 단계에서, 화면에 뭐라고 떴는지 알려주세요. 그것만 있으면 원인을 찾을 수 있습니다.
