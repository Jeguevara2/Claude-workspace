# 현장 캡처 → 파이 (PWA)

폰 카메라/마이크로 현장 영상·회의 녹음을 찍어서 개인 구글드라이브의 전용 폴더로 바로 올리는 앱. 실시간 분석은 하지 않고, 업로드만 해두면 이후 Claude 채팅에서 파이에게 "이 폴더에서 이 파일 보고 정리해줘"라고 요청하는 식으로 이어받는다(기존 "화면녹화+음성지시" 워크플로우와 동일한 패턴).

- 영상 촬영 → 건설기술 학습 자료 정리용
- 음성 녹음 → 회의록 자동 제작용

서버 없이 정적 파일만으로 동작하는 PWA. Google Drive 접근은 `drive.file` 스코프만 사용 — 이 앱이 만든 파일/폴더만 볼 수 있고 드라이브 전체를 읽지 않는다.

## 1. Google OAuth 클라이언트 발급 (최초 1회, 개인 구글 계정 jechanghyun@gmail.com 기준)

1. https://console.cloud.google.com 접속 → 새 프로젝트 생성 (예: `site-capture`)
2. 좌측 메뉴 "API 및 서비스 → 라이브러리"에서 **Google Drive API** 검색 → 사용 설정
3. "API 및 서비스 → OAuth 동의 화면"
   - User Type: 외부(External)
   - 앱 이름: 아무 이름 (예: 현장캡처)
   - 테스트 사용자에 본인 이메일(jechanghyun@gmail.com) 추가
   - 배포하지 않고 "테스트" 상태로 두면 됨 (개인 전용이라 검수 불필요)
4. "API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID"
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 자바스크립트 원본에 배포할 주소 추가 (2단계에서 정할 GitHub Pages 주소, 예: `https://jeguevara2.github.io`)
   - 생성 후 나오는 **클라이언트 ID**(`xxxxx.apps.googleusercontent.com`) 복사
5. 앱을 폰에서 연 뒤 우측 상단 ⚙️ 설정에 이 클라이언트 ID를 붙여넣고 저장 (기기에만 저장되고 어디로도 전송되지 않음)

## 2. 배포 (GitHub Pages)

이 폴더(`apps/site-capture/`)를 정적 호스팅에 올리면 된다. 이 저장소 기준 가장 간단한 방법:

1. GitHub 저장소 → Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: 이 작업이 올라간 브랜치(또는 main 병합 후 main) / 폴더: **/docs**
   - Pages는 `/docs` 또는 저장소 루트만 선택 가능하므로, 병합 시 이 폴더를 `docs/site-capture/`로 옮기거나, 이 저장소를 Pages 전용으로 쓸 경우 `docs/` 채로 유지
4. 저장하면 몇 분 후 `https://<계정>.github.io/<저장소>/site-capture/` 형태의 주소가 생성됨
5. 그 주소를 1단계 "승인된 자바스크립트 원본"에 등록한 주소(오리진, 경로 없이 `https://<계정>.github.io`)와 맞춘다

## 3. 폰에 설치

1. 폰 브라우저(Chrome/Safari)로 배포 주소 접속
2. 카메라/마이크 권한 허용
3. 브라우저 메뉴 → "홈 화면에 추가" → 앱 아이콘으로 설치됨 (Play스토어 등록 불필요, 내 폰에서만 동작)
4. 최초 1회 ⚙️ 설정에서 클라이언트 ID 입력 → "구글드라이브 연결" → 구글 로그인/동의
5. 이후 🎥/🎙️ 버튼으로 촬영·녹음 → 라벨(현장명/메모) 입력 → 업로드

앱이 최초 연결 시 드라이브에 `현장수신함` 폴더(설정에서 이름 변경 가능)를 자동 생성하고, 이후 모든 파일을 그 폴더에 올린다.

## 4. 오프라인/실패 처리

- 현장은 전파가 약할 수 있어, 촬영 직후 업로드가 실패하면 기기 내(IndexedDB)에 원본이 남아 "업로드 내역"에 **실패** 상태로 표시된다.
- 다시 인터넷이 연결되거나 앱을 다시 열면 자동 재시도하고, 수동으로 "재전송" 버튼도 누를 수 있다.
- 업로드 성공한 파일은 용량 절약을 위해 기기 내 원본을 지우고 상태만 "완료"로 남긴다.

## 5. 파이에게 넘기기

업로드가 끝나면 화면 하단에 아래 형태의 문구가 자동으로 채워지고, "문구 복사" 버튼으로 복사할 수 있다:

> 구글드라이브 "현장수신함" 폴더에서 "VIDEO_20260727_1432_A현장.webm" 파일 찾아서 건설기술 학습 자료로 정리해줘.

이 문구를 Claude 채팅(파이)에 붙여넣으면, 개인 계정에 연결된 Google Drive 커넥터로 파이가 해당 폴더/파일을 찾아 학습하거나 회의록으로 정리한다.

## 파일 구성

- `index.html` / `style.css` / `app.js` — 앱 본체 (프레임워크 없는 순수 JS)
- `manifest.json` / `sw.js` — PWA 설치·오프라인 캐시
- `icons/` — 앱 아이콘 (임시 생성본, 원하면 교체 가능)
